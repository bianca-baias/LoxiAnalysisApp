# LoxiAnalysisApp
LoxiAnalysis is an application that uses a trained YOLO model to analyse a Valorant vieo gameplay. In the end, the application calculates statistics about the aim of an individual, it interprets them and generates a score.

UI:
- I used PySide6 for development;

Analysis:
- I trained a YOLO model to detect objects (bot, head, shot, headshot, kill) in a Valorant - mode The Range video
